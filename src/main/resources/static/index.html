🍕 Bem-vindo ao Backoffice Bella Roza

Esta interface conecta-se diretamente com a API Spring Boot. Aqui você pode gerenciar todo o fluxo de retaguarda da pizzaria. No painel abaixo, você pode inspecionar os detalhes técnicos das requisições REST.

Recursos de Segurança & Controle da API

  • Segurança por Chave de API: As requisições (exceto autenticação) exigem a chave do header X-API-Key. Você pode utilizar a chave mestre padrão ou criar uma chave exclusiva atrelada a um dono na aba "Gerar Nova Chave".
  • Garantia de Idempotência: O cadastro de Clientes e Pedidos envia automaticamente um cabeçalho X-Idempotency-Key. Se a mesma requisição for disparada repetidamente (ex: cliques duplos), o backend processará apenas uma vez, evitando cadastros e cobranças duplicadas.
  • Rate Limiting (Controle de Tráfego): A API restringe requisições a no máximo 20 chamadas por minuto. Tente atualizar as abas rapidamente para disparar o erro 429 Too Many Requests e observe o painel de alerta.
